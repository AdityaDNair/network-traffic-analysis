\# SIEM Basics



\## Overview



Security Information and Event Management (SIEM) is a cybersecurity solution used to collect, analyze, correlate, and monitor logs from multiple systems and devices.



SIEM platforms help organizations:

\- detect threats

\- investigate incidents

\- monitor security events

\- centralize log management



SIEM tools are widely used in SOC environments.



\---



\## Main Functions of SIEM



A SIEM platform typically performs:

\- log collection

\- event correlation

\- alert generation

\- incident investigation

\- reporting



\---



\## Log Collection



SIEM platforms collect logs from:

\- servers

\- firewalls

\- endpoints

\- cloud services

\- Active Directory

\- applications



Centralized logging improves visibility across environments.



\---



\## Event Correlation



Correlation combines multiple events to identify suspicious patterns.



Example:

\- multiple failed logins

\- followed by successful login

\- followed by privilege escalation



This may indicate account compromise.



\---



\## Alerting



SIEM systems generate alerts when suspicious behavior is detected.



Examples:

\- brute force attacks

\- malware activity

\- unauthorized access attempts

\- unusual network traffic



\---



\## Common SIEM Platforms



Popular SIEM solutions:

\- Splunk

\- IBM QRadar

\- Microsoft Sentinel

\- Elastic SIEM

\- ArcSight



\---



\## SIEM in SOC Operations



SOC analysts use SIEM platforms for:

\- alert monitoring

\- threat investigation

\- incident response

\- log analysis



SIEM is often the primary tool used inside a SOC.



\---



\## Example SIEM Workflow



1\. Logs are collected

2\. Events are correlated

3\. Alerts are generated

4\. Analysts investigate suspicious activity

5\. Incidents are escalated if necessary
