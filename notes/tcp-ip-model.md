TCP/IP Model Overview

February 20 2026

Objective - To understand the TCP/IP model and how it differs from the OSI model.

TCP/IP Layers
1. Application – Provides network services to applications (HTTP, FTP, DNS).
2. Transport – Ensures data delivery using TCP or UDP.
3. Internet – Handles logical addressing and routing (IP).
4. Network Access – Manages physical transmission of data.

Comparison with OSI Model
- TCP/IP has fewer layers than OSI.
- OSI is a conceptual model, TCP/IP is practical.
- OSI separates Session and Presentation layers, TCP/IP combines them.

Key Observations
- Most real-world networks follow the TCP/IP model.
- Protocols like HTTP and DNS operate at the Application layer.

Reflection - Understanding the TCP/IP model helps in analyzing real network traffic and protocol behavior.
