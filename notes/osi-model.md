OSI Model Overview

February 19, 2026

Objective - To understand the 7-layer OSI model and how data flows through network layers.

Brief about the 7 Layers
1. Application – Interface for user applications (HTTP, FTP).
2. Presentation – Data formatting, encryption, compression.
3. Session – Manages communication sessions.
4. Transport – Ensures reliable transmission (TCP/UDP).
5. Network – Handles logical addressing (IP).
6. Data Link – Physical addressing (MAC).
7. Physical – Transmits raw bits over a medium.

Key Observations
- Each layer has a specific responsibility.
- TCP operates at the Transport layer.
- IP operates at the Network layer.
- Encryption can occur at the Presentation layer.

Reflection - Understanding the OSI model helps in identifying where network issues or attacks occur.
