Firewalls Basics

Date - 14th March, 2026

Objective - To understand what firewalls are, how they work, and their role in network security.

What is a Firewall?
- A firewall is a network security device or software that monitors and controls incoming and outgoing network traffic based on predefined security rules.
- It acts as a barrier between trusted internal networks and untrusted external networks.

Types of Firewalls
1) Packet Filtering Firewall
- Examines packets based on IP address, port number, and protocol
- Simple and fast but limited in inspection capability

2) Stateful Firewall
- Tracks active connections and makes decisions based on connection state
- More secure than basic packet filtering

3) Application Layer Firewall (Proxy Firewall)
- Inspects application-level traffic (e.g., HTTP)
- Provides deeper security inspection

Firewall Functions
- Blocks unauthorized access
- Allows legitimate traffic
- Enforces security policies
- Helps prevent attacks such as port scanning

Security Relevance
- Firewalls are essential for network perimeter defense
- They reduce exposure to external threats
- Must be configured properly to avoid security gaps

Reflection - Understanding firewalls is critical for designing secure network architectures and monitoring network traffic.
