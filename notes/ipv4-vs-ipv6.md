IPv4 and IPv6 Basics

Date - 28th February, 2026

Objective - To understand the differences between IPv4 and IPv6 addressing and why IPv6 was introduced.

IPv4
- Uses 32-bit addressing
- Written in dotted-decimal format (e.g., 192.168.1.1)
- Limited address space (~4.3 billion addresses)
- Commonly used with NAT to conserve addresses

IPv6
- Uses 128-bit addressing
- Written in hexadecimal format separated by colons
- Vast address space
- Designed to replace IPv4 and reduce reliance on NAT

Key Differences
- IPv6 provides a significantly larger address space
- IPv6 supports auto-configuration
- IPv6 includes built-in security features like IPsec support

Security Relevance
- NAT in IPv4 can obscure internal addresses but is not a security feature
- IPv6 requires proper firewall configuration due to global addressing
- Understanding IP versions is important for secure network design

Reflection - Learning IPv4 and IPv6 fundamentals helps in understanding modern network infrastructure and security considerations.
