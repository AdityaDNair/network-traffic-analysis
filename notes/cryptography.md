\# Cryptography Basics



\## Overview



Cryptography is the practice of securing information through mathematical techniques such as encryption, hashing, and digital signatures.



It is used to protect:

\- confidentiality

\- integrity

\- authentication

\- non-repudiation



Cryptography is a fundamental part of modern cybersecurity.



\---



\## Encryption



Encryption converts readable data (plaintext) into unreadable data (ciphertext).



Only authorized users with the correct key can decrypt the information.



\---



\## Symmetric Encryption



Symmetric encryption uses the same key for both encryption and decryption.



Advantages:

\- fast

\- efficient



Disadvantages:

\- key distribution challenges



Examples:

\- AES

\- DES

\- Blowfish



\---



\## Asymmetric Encryption



Asymmetric encryption uses:

\- a public key

\- a private key



The public key encrypts data while the private key decrypts it.



Examples:

\- RSA

\- ECC



\---



\## RSA Encryption



RSA is one of the most widely used asymmetric encryption algorithms.



Common uses:

\- secure communication

\- digital certificates

\- HTTPS encryption



\---



\## AES Encryption



Advanced Encryption Standard (AES) is a widely used symmetric encryption algorithm.



Common key sizes:

\- 128-bit

\- 192-bit

\- 256-bit



AES is commonly used in:

\- VPNs

\- disk encryption

\- Wi-Fi security



\---



\## Hashing



Hashing converts data into a fixed-length value called a hash.



Properties:

\- one-way function

\- deterministic

\- difficult to reverse



Examples:

\- SHA-256

\- SHA-512

\- MD5 (insecure)



\---



\## Uses of Hashing



Hashing is commonly used for:

\- password storage

\- integrity verification

\- digital signatures



\---



\## Salting Passwords



Salting adds random data before hashing passwords.



Benefits:

\- prevents rainbow table attacks

\- improves password security



\---



\## Digital Signatures



Digital signatures verify:

\- authenticity

\- integrity

\- non-repudiation



They are commonly used in:

\- software signing

\- secure email

\- certificates



\---



\## SSL/TLS



SSL/TLS protocols use cryptography to secure internet communications.



Used in:

\- HTTPS websites

\- VPNs

\- secure email



\---



\## Public Key Infrastructure (PKI)



PKI manages:

\- certificates

\- public keys

\- certificate authorities (CAs)



PKI is essential for secure communications.



\---



\## Common Cryptographic Attacks



Examples:

\- brute force attacks

\- man-in-the-middle attacks

\- weak key attacks

\- downgrade attacks



\---



\## Importance in Cybersecurity



Cryptography protects:

\- sensitive data

\- online transactions

\- authentication systems

\- network communications



\---



\## Conclusion



Cryptography is a core component of cybersecurity that enables secure communication, protects sensitive information, and supports authentication and data integrity across modern systems and networks.
