TCP vs UDP

Date - 9th March, 2026

Objective - To understand the differences between Transmission Control Protocol (TCP) and User Datagram Protocol (UDP) and their use cases.

TCP (Transmission Control Protocol)
- Connection-oriented protocol
- Ensures reliable data transmission
- Uses acknowledgments and retransmissions
- Maintains ordered delivery of packets

TCP Characteristics
- Three-way handshake used to establish connection
- Error checking and flow control
- Higher overhead but more reliable

Common TCP Applications
- HTTP / HTTPS
- FTP
- SMTP
- SSH

UDP (User Datagram Protocol)
- Connectionless protocol
- Faster but less reliable
- No guarantee of packet delivery
- No retransmission or ordering

UDP Characteristics
- Lower overhead
- Suitable for real-time communication
- Faster transmission

Common UDP Applications
- DNS
- VoIP
- Online gaming
- Streaming services

Key Differences

Security Relevance - Understanding TCP and UDP is essential for analyzing network traffic and identifying malicious activities during packet inspection.

Reflection - TCP and UDP serve different purposes in networking. Choosing the right protocol depends on whether reliability or speed is more important for the application.
