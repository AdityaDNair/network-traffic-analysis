Subnetting and CIDR Basics

Date - 1st March, 2026

Objective - To understand subnetting and Classless Inter-Domain Routing (CIDR) and how IP networks are divided.

What is Subnetting?
- Subnetting is the process of dividing a larger IP network into smaller subnetworks.
- It improves network organization and security.
- It reduces broadcast traffic.

CIDR (Classless Inter-Domain Routing)
- CIDR uses prefix notation (e.g., /24).
- The number after "/" represents the number of bits used for the network portion.
- Example:
  - 192.168.1.0/24 → 24 bits for network, 8 bits for hosts
  - Allows 256 total addresses (254 usable hosts)

Why Subnetting is Important
- Efficient IP address allocation
- Improved performance
- Better network segmentation

Security Relevance
- Subnetting enables network segmentation.
- Helps isolate sensitive systems.
- Reduces attack surface inside internal networks.

Reflection - Understanding subnetting is essential for designing scalable and secure networks.
