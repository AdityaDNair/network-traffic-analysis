Common Ports and Protocols

Date - 10th March, 2026

Objective - To understand common network protocols and the ports they use for communication.

What is a Port?
- A port is a logical communication endpoint used by network protocols to send and receive data.
- Ports help systems identify which service or application should receive incoming traffic.

HTTP (Hypertext Transfer Protocol)
- Port: 80  
- Protocol Type: TCP

Purpose:
- Used for transferring web pages and resources over the internet
- Data is transmitted in plaintext

Security Note:
HTTP does not encrypt traffic, making it vulnerable to interception.


HTTPS (Hypertext Transfer Protocol Secure)
- Port: 443  
- Protocol Type: TCP

Purpose:
- Secure version of HTTP
- Uses SSL/TLS encryption to protect data

Security Note:
Provides confidentiality and integrity for web communications.

FTP (File Transfer Protocol)
- Port: 21 (control connection)

Purpose:
- Used to transfer files between systems
- Supports upload and download operations

Security Note:
Traditional FTP transmits credentials in plaintext.

SSH (Secure Shell)
- Port: 22  
- Protocol Type: TCP

Purpose:
- Secure remote login and command execution
- Often used to manage servers remotely

Security Note:
Encrypts communication to prevent unauthorized access.

Key Observations
- Ports allow multiple services to run on a single device.
- Each protocol typically operates on a well-known port.

Security Relevance- Understanding common ports and protocols helps in network monitoring, firewall configuration, and intrusion detection.

Reflection- Knowledge of ports and protocols is fundamental for analyzing network traffic and identifying suspicious activity.
